# Cross-Market Discovery Research

**日期：** 2026-06-07  
**类型：** 只读统计研究（未修改 Agent / runtime / 策略 / 风控 / orchestrator）  
**原始数据：** `research/p0d_discovery_scratch.json`、`research/p0d_discovery_extra.json`

---

## 1. 研究问题

检验三类跨市场关系：

| 方向 | 市场对 | 关注现象 |
|------|--------|----------|
| A. Crypto 内部 | BTC / ETH / SOL | lag / lead、spillover、波动率传导 |
| B. Crypto → Polymarket | BTC → PM Crypto 市场 | 价格、成交量、波动率、资金费率领先 |
| C. ETF → Crypto | MSTR / MSTX / TSLL / NVDA → BTC / ETH | 共同驱动、提前信号 |

**统计约定：**

- 收益率相关：Pearson 相关系数 \(r\)
- 领先定义：`lag > 0` 表示 **市场 A 领先市场 B**（A 的过去变动与 B 的当前变动最相关）
- 显著性：\|t\| > 2（约对应 α≈5%），\(t = r\sqrt{(n-2)/(1-r^2)}\)
- 日频窗口：±5 日；小时频窗口：±3 小时

## 7. 核心发现（回答研究目标）

### 7.1 哪些市场存在统计关联？

1. **Crypto 内部：** BTC–ETH–SOL 在收益、波动率、交易量上 **高度同期相关**。
2. **ETF ↔ Crypto：** 科技/半导体杠杆 ETF（QQQ、TQQQ、SOXL）与 BTC/ETH **中等偏强同期相关**；SOXS 呈显著负相关。
3. **Crypto ↔ Polymarket：** 事件窗内 PM_PROXY 与 BTC/ETH **强相关**；真 PM 市场仅 1 个（556108）显示弱显著 **BTC 领先 1 小时** 信号。
4. **MSTR / MSTX / TSLL / NVDA：** 本次 **无法检验**。

### 7.2 关联强度

- **强（\|r\| > 0.7）：** BTC↔ETH 日频/短窗小时、波动率同步、OKX 活动量、BTC↔PM_PROXY 事件窗
- **中（0.3–0.7）：** ETF↔Crypto 日频、BTC↔SOL OKX PnL、BTC→PM#556108 @lag+1h
- **弱/不显著：** BTC↔ETH OKX PnL 小时、PM liquidity 变动

### 7.3 领先时间

- **绝大多数配对：lag = 0**（同期共动，非 A 领先 B）
- **唯一弱显著领先：** BTC 价格 **+1 小时** 领先 PM #556108（MegaETH airdrop 市场）
- **日频 ETF → Crypto：** 无 ±5 日领先结构

### 7.4 样本数与显著性

| 层级 | 典型 n | 可信度 |
|------|--------|--------|
| Crypto 日频 | 1,617 | 高 |
| ETF 日频 | 1,109 | 高 |
| Replay 事件窗 | 320–346 | 中 |
| OKX 探索小时 | 65 | 中 |
| PM / Crypto 小时 | 13–14 | **低** |

### 7.5 未来是否值得持续观察？

| 优先级 | 观察对 | 理由 |
|--------|--------|------|
| **P0** | BTC ↔ ETH（日频收益 + 波动率） | 最强基线；监测相关破裂 = regime 变化 |
| **P0** | QQQ/TQQQ/SOXL ↔ BTC/ETH（日频） | 稳定共同驱动；宏观风险通道 |
| **P1** | BTC → 真 PM Crypto 市场价格 | 有弱领先信号；需更长 PM 历史与更多市场 |
| **P1** | BTC ↔ PM_PROXY（事件窗） | 直至真实 PM tape 接入 |
| **P2** | BTC ↔ SOL（日频 + OKX 小时） | SOL 日频缺失；小时样本仍短 |
| **P2** | OKX 跨币种活动量 | 高相关但无领先；可作同步性健康指标 |
| **待建** | MSTR/MSTX/TSLL/NVDA → BTC/ETH | 用户指定标的，当前无历史 |
| **待建** | Funding rate 领先链 | 需 pyarrow + funding 时间序列 |
