## 🎯 策略核心

### 基本逻辑
1. **买入**: 在 5 分钟 BTC 市场买入 1¢ outcome（$5 投入）
2. **挂单**: 立即在 2¢ 挂卖单
3. **等待**: 2 分钟超时
4. **结局**:
   - ✅ 2¢ 成交 → +$5 (+100%)
   - ❌ 归零 → -$5 (-100%)
   - 🎰 到期赢 → +$495 (+9900%)

### 数学模型
```
EV = P(2¢成交) × $5 + P(归零) × (-$5) + P(到期赢) × $495
   = 0.50 × $5 + 0.486 × (-$5) + 0.014 × $495
   = $2.5 - $2.43 + $6.93
   = $7.00 (+140%)
```

### 关键假设
- **2¢ 成交概率**: 50%（需要验证）
- **真实概率**: 1.4%（市场定价准确）
- **流动性**: 1¢ 和 2¢ 都有足够流动性
- **手续费**: 1.8% 往返（Crypto 市场）

## ⚠️ 关键风险

### 1. 流动性枯竭
- **问题**: 如果更多人抄这个策略，1¢ 流动性会被抢光
- **监控**: 每小时记录 1¢ 流动性变化
- **应对**: 如果流动性下降 50%，立即停止

### 2. 2¢ 成交率下降
- **问题**: 如果 2¢ 成交率 < 40%，EV 变负
- **监控**: 每天记录 2¢ 成交率
- **应对**: 如果成交率 < 40%，调整策略或停止

### 3. 手续费侵蚀
- **问题**: 1.8% 往返手续费会吃掉部分利润
- **计算**: 净利润 = $5 - $0.09 - $0.08 = $4.83
- **影响**: EV 从 $7.00 降到 $6.66（-5%）

### 4. 真实概率 > 1.4%
- **问题**: 如果真实概率 > 2%，到期赢的频率会增加，但归零频率也会增加
- **监控**: 记录实际胜率
- **应对**: 如果胜率 > 3%，重新计算 EV

### 5. 执行速度
- **问题**: lil222 可能使用了毫秒级执行，我们的系统是 30 秒扫描
- **影响**: 可能抢不到 1¢ 流动性
- **应对**: 升级到 WebSocket 实时监控
